# Preprocessing documentation

`tm5_spectral_fluxes.md` describes the TM5 spectral construction and validation.
[Section 17](tm5_spectral_fluxes.md#17-synthesis-backends-and-measurements)
covers CPU bitwise shape independence and portable GPU face quadrature.

report T255/T639 scale-aware face errors, balanced am/bm/cm errors, complete
LL 1°/C90 timing and device memory, with explicit residual-bound failures.
