Output and visualization API ​

Output defines snapshot capture and persistence, and observation sampling ([output.observations]: point events and station series sampled at met-window ends). Visualization provides topology-aware field views and optional Makie rendering for those snapshots.

Output ​

AtmosTransport.Output Module
julia
Output

Topology-aware diagnostic output for AtmosTransport runtime products.

This module owns the public NetCDF output contract. Runtime code should capture model state with capture_snapshot and write files with write_snapshot_netcdf instead of defining ad-hoc NetCDF layouts in runner code.

The writer is intentionally topology-dispatched:

  • LatLonMesh writes regular CF lon/lat coordinates.

  • ReducedGaussianMesh writes native cell-indexed diagnostics plus a legacy lon/lat raster view for current debug plots.

  • CubedSphereMesh writes panel-native diagnostics with GEOS-style lons, lats, corner_lons, corner_lats, cell_area, and cubed_sphere metadata so Panoply and downstream tools have enough geometry context to render C-grid snapshots.

New topologies should add methods for the small internal schema/diagnostic functions in this folder; they should not special-case the runner.

Output also owns observation sampling (observations/): the [output.observations] contract, source readers, containing-cell locators, the device column gather, and the append-only _soundings / _sites NetCDF files written by build_observation_sampler's sampler.

AtmosTransport.Output.AbstractPressureBasis Type
julia
AbstractPressureBasis

The vertical basis of a column's placement (pressure_basis), one choice for the interface pressures a pressure-placed record (or an averaging-kernel column) is compared with and for the hypsometric layer heights a record placed by height is compared with: TotalFromHumidity (default) or DryInterfaces. A record's pressure is the total (ambient) pressure, dry air plus water vapour. The air mass of a dry-basis run gives dry interface pressures, pk+1/2=pk−1/2+gmk/A (the weight of the dry air above), which are lower than the total pressure at the same interface by the weight of the water vapour above it: about 0.5 % of the surface pressure for 50 kg m⁻² of precipitable water. The hydrostatic layer thickness is (RdTv/g)ln⁡(pk+1/2/pk−1/2) with total pressures and the virtual temperature Tv=T(1+0.61q); dry pressures and T put heights in a humid boundary layer about 2 % low.

AtmosTransport.Output.DryInterfaces Type

pressure_basis = "dry": compare a record's pressure with the dry interface pressures pk+1/2=pk−1/2+gmk/A of a dry-basis run, and its height with the hypsometric heights on them with the layer temperature T, zk−1/2=zk+1/2+(RdTk/g)ln⁡(pk+1/2/pk−1/2), for runs whose binaries carry no humidity (the sampler's only rule before issue #20). Both are approximations. The dry interfaces lie at lower pressure than the total ones, so a record can be placed one or more layers lower in the column than its total pressure says, most likely near the surface where the vapour weight above an interface is largest and the layers are thinnest. The heights are low by the dry pressure ratio (−q plus the vapour weight above over the pressure) and by T against Tv (−0.61q): about 2 % in a humid tropical boundary layer (q = 16 g/kg), 6 m at a 300 m intake. Not available on a moist-basis run.

AtmosTransport.Output.HatLevelProjection Type
julia
HatLevelProjection()

Retrieval values sit on N levels and the profile is linear in pressure between them: the OCO-2 and OCO-3 retrievals (20 levels, "defined on layer boundaries", the first at σ=10−4), whose pressure weights are the integrals of the levels' hat functions (the trapezoid rule with half-thickness end levels, with a dry-air correction). The model column, stretched onto the retrieval levels (top level to bottom level), is projected onto the retrieval's basis, the hat functions φj of the levels (φj(pj)=1, linear to 0 at the neighbouring levels): the level values c are the L2 (Galerkin) projection in dry air,

∑iMjici=bj,Mji=∫φjφidpdry,bj=∫φjxdpdry=∑kBjkxk,Bjk=mkΔsk∫sk−1/2sk+1/2φj(p)dp,

so P=M−1B, with each stretched model layer k (air mass mk, the run's dry air mass by default) spread evenly over its pressure thickness Δsk; M is tridiagonal. The hats sum to 1 over the stretched column, so the rows of P sum to 1 and, with the hat integrals hj=∑kBjk/∑kmk as weights, ∑jhjcj is the model's air-mass-weighted column mean: the projection conserves the column. It reproduces every profile the retrieval can represent (piecewise linear on the levels), to the discretization of the model's layer means. P, the inverse of the consistent mass matrix times B, has negative entries in general (about −0.2 in every row on a GEOS L72 column); the weights H=(h∘a)TP of OCO-2 retrievals stayed positive in the cases measured. Stored as retrieval_mapping = "hat_levels".

AtmosTransport.Output.RetrievalColumn Type
julia
RetrievalColumn(pressure_pa, pressure_weight, averaging_kernel, prior_profile,
                profile_sigma, surface_pressure_pa[, mapping = LayerRebin()[, prior_column = NaN]])
RetrievalColumn(; pressure_pa, pressure_weight, averaging_kernel, prior_profile,
                  profile_sigma = Float64[], surface_pressure_pa = first(pressure_pa),
                  mapping = LayerRebin(), prior_column = NaN)

The vertical description of one retrieved column average (a satellite or TCCON sounding) with N retrieval values, ordered from the surface up. The mapping (AbstractRetrievalMapping) says what the values are:

  • LayerRebin: means over N layers; pressure_pa holds the N + 1 layer interfaces;

  • HatLevelProjection: values on N ≥ 2 levels, the profile linear in pressure between them (OCO-2/OCO-3); pressure_pa holds the N level pressures.

Fields:

  • pressure_pa: the interfaces or levels (Pa, total pressure), surface first, strictly decreasing; the last is the retrieval top (≥ 0);

  • pressure_weight: the pressure weights hi (N, ≥ 0, summing to 1 within RETRIEVAL_WEIGHT_SUM_TOLERANCE);

  • averaging_kernel: the column averaging kernel ai (N, normalized, dimensionless: ∂X/∂xi=hiai);

  • prior_profile: the retrieval prior xa,i (N, dry mole fraction, mol mol⁻¹, in [0, 1]);

  • profile_sigma: optional 1-σ uncertainty σi of the model profile on the retrieval layers or levels (N, mol mol⁻¹, in [0, 1]; empty when absent), the input of the model-error term retrieval_model_error_variance. It is not the retrieval's a-priori uncertainty: the smoothing error is already represented by the averaging kernel;

  • surface_pressure_pa: the retrieval surface pressure (Pa), equal to the first pressure (relative tolerance 1e-6);

  • mapping: the AbstractRetrievalMapping;

  • prior_column: optional, the retrieval's prior column Xa (mol mol⁻¹, in [0, 1]; NaN when absent), e.g. the OCO-2 xco2_apriori. When given, the column is X=Xa+∑ihiai((Px)i−xa,i) (the MIP protocol's eq. 2); without it Xa=∑ihixa,i. The two differ when the weights and the prior were averaged separately (OCO-2 10-s averages: a few thousandths of a ppm).

Every value but an absent prior_column must be finite. See retrieval_column_weights! for the operator.

AtmosTransport.Output.SnapshotFrame Type
julia
SnapshotFrame

CPU-resident snapshot of one model state at one output time.

air_mass and each entry in tracers keep the topology-native storage shape:

  • LL: (lon, lat, lev)

  • RG: (cell, lev)

  • CS: NTuple{6, Array{T, 3}} with panel interiors (Xdim, Ydim, lev)

Tracer arrays store the model's conservative χ × carrier-air-mass quantity, not mixing ratio or physical kg species. Derived VMR and column diagnostics are computed by write_snapshot_netcdf. tracer_total_mass stores a compensated Float64 sum of that conservative quantity for every tracer. It is kept separately so Float32 visualization payloads cannot degrade global signed mass diagnostics through cancellation or output conversion.

Snapshot storage must be CPU-resident. Use capture_snapshot for model state on any backend; it strips cubed-sphere halos and copies device arrays to the host before constructing the frame.

AtmosTransport.Output.TotalFromHumidity Type

pressure_basis = "total" (default): compare a record's pressure with the column's total interface pressures, and a record's height with the hypsometric heights of moist air on them. Specific humidity qk (kg of water vapour per kg of moist air) makes the moist air mass of layer k mk/(1−qk) for a dry air mass mk (kg), so on a dry-basis run the hydrostatic total pressures and the interface heights above the model surface are

p1/2=ptop,pk+1/2=pk−1/2+gmkA(1−qk),zk−1/2=zk+1/2+RdTk(1+cqk)gln⁡pk+1/2pk−1/2,

with zN+1/2=0, Tk the layer temperature, c=Rv/Rd−1 (VIRTUAL_TEMPERATURE_FACTOR, 0.61) and Tk(1+cqk) the virtual temperature (exact for layers of uniform T and q), A the cell area and ptop the pure-pressure model-top interface A_ifc[1], a total pressure in the met model's hybrid coordinate (level 1 is the top). This inverts the preprocessing's dry conversion Δpdry=(1−q)Δp. On merged or remapped levels the binary carries a dry-mass-weighted q, so the inverse is not exact there; on the golden pre_ll72 binary (ERA5 L137 merged to 34 levels) the rebuilt total surface pressure differs from the stored one by −0.012 Pa on average and 0.125 Pa at most, where the dry interfaces are 169 Pa low on average and 700 Pa at worst. The humidity is the binary's layer-mean specific humidity at the sampled boundary: qv_start / qv_end of lat-lon binaries preprocessed with output.include_qv = true; on cubed-sphere binaries with the GCHP VDIFF payload the window-start VDIFF qv of the next window (the run's last window end takes the ended window's, one window old). Reduced-Gaussian binaries, and cubed-sphere binaries without the VDIFF payload, carry no humidity. On a moist-basis run the air mass already includes the vapour and its interfaces are total pressures without humidity; the heights there use T (no humidity is gathered, so the virtual-temperature term, about 1 % of the heights in a humid boundary layer, is neglected). A dry-basis run whose binaries do not all carry humidity cannot build them: building a sampler with any request, whatever its vertical coordinate (every row reports its layer's heights), then fails unless pressure_basis = "dry".

AtmosTransport.Output.VerticalPlacement Type

AtmosTransport.Output.resolve_placement Method
julia
resolve_placement(spec::VerticalPlacementSpec, missing_height, request, cell, terrain)
    -> Union{VerticalPlacement, Nothing}

Place a SoundingRequest or SiteRequest in the column of its containing cell by the first of spec.coordinates (AbstractVerticalCoordinate, in preference order) that places it:

  • HeightAboveGroundCoordinate: the record's height above ground h (intake_height, or altitude − elevation with the record's or station's elevation; record_height), else h = altitude minus the DEM ground elevation at the point (altitude_minus_dem). The record is placed h above the model surface.

AtmosTransport.Visualization.fieldview Method
julia
fieldview(snapshot, variable; transform=ColumnMean(), time=1, level=nothing, unit=NativeUnit())

Load one topology-native horizontal field from a snapshot file.

time may be a one-based frame index or a snapshot hour. For CS snapshots, transform may be ColumnMean(), ColumnSum(), LevelSlice(), or SurfaceSlice(). Stored CS column means support column-only output; level selection uses original model indices and rejects levels that were not written. LL/RG snapshots currently support ColumnMean() only.
