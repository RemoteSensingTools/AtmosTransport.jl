Adjoints and checkpointing API ​

The adjoint surface covers cubed-sphere objectives, observations, footprints, preconditioning, and 4D-Var solvers. Tape owns checkpoint schedules and device, pinned-host, and memory-mapped tape storage.

Adjoints ​

Configure optimizer settings and logging on CSGradientDescent or CSLBFGS and pass it as optimizer to cs_surface_flux_4dvar_optimize. Footprint functions compute analytic adjoints; finite-difference perturbations belong to the caller's validation code. CSFootprintResult contains objective, footprints, lag_steps, dt, and initial_adjoint.

AtmosTransport.Adjoints Module
julia
Adjoints

Prototype adjoint and footprint utilities.

The shipped path is a kernelized cubed-sphere reverse pass for tracer mass with fixed meteorology/air-mass evolution. It accumulates surface-emission footprints (and the initial-condition sensitivity) from an adjoint seed or observation forcing without perturbing each surface cell.

The forward model is the production step by construction: the adjoint replays the production StepPlan (CSStepSchedule: physics cadence, met windows, air-mass resets) with the production operators on a single-tracer state, records its tape through the recorder hooks of the production step (Operators.AbstractStepRecorder) and walks the tape backwards with each operator's adjoint. require_adjoint_support rejects a plan containing an operator without an adjoint before anything is recorded.

It is false for a co-sampled record (its flag, the record's, is not 0: flagged_records = "cosample"), for a record averaged into a cell average (cell_average_id, the number of the average, 1, 2, … in observation order, is not 0; the average is in the cost, the record is reported on its own), and for an averaging-kernel column the surface-pressure screen left out; a row with a nonzero flag or a cell average is never assimilated.

Over the assimilated rows, ∑normalized_departure2=2Jobs. The constructor rejects non-finite values and checks the sign convention departure = simulated_value − observed_value and normalized_departure = departure / σ, σ=value_sigma2+model_sigma2+profile_model_sigma2.

AtmosTransport.Adjoints.CSFootprintResult Type
julia
CSFootprintResult

Reverse-mode result for one scalar objective. footprints[t] is an NTuple{6} of (Nc, Nc) arrays containing dJ / dE, where E is the per-cell model-storage emission rate the surface-flux operator applies at the palindrome center of model step t. Storage is dry mixing ratio × carrier-air mass; these rates are not physical kg-species per second and are not divided by cell area. The derivative includes the timestep factor. lag_steps[t] == nsteps - t. A step plan without a surface-flux operator (surface_flux = false) has no emission entry point and an empty footprints.

initial_adjoint is dJ/drm at the initial state: an NTuple{6} of halo-padded panels like the initial tracer mass (the halo cells are zero: halos are a function of the interiors).

CSGradientDescent(; iterations, initial_step, min_step,

Plain backtracking-line-search gradient descent. iterations is the maximum count of accepted descent steps; the loop terminates early when the gradient L2 norm falls below gradient_tolerance or the line search shrinks step below min_step. AtmosTransport.Adjoints.CSLBFGS Type
julia
CSLBFGS(; iterations, gradient_tolerance, m, show_trace, log)

Limited-memory BFGS (L-BFGS) optimizer backed by Optim.jl. m is the history length; the line search is Optim's LBFGS default (Hager–Zhang). iterations is the max outer iteration count; gradient_tolerance is Optim's L-infinity stopping threshold on the χ-space / x-space gradient. The same L-infinity norm is recorded in gradient_norm_history and CSIterationLogEntry.gradient_norm for this backend. show_trace = true forwards verbose progress to Optim's logger. log = true records one CSIterationLogEntry for the initial state (iteration 0) and one per accepted iterate.

Used by the polymorphic dispatch surface cs_surface_flux_4dvar_solve. The cost closure cost_fn(controls) -> CS4DVarResult is handed to Optim as one objective with value, gradient and combined value-and-gradient methods, flattening each control's NTuple{6, Matrix} to a Vector{FT} and back. Each cost_fn call is a forward run plus the adjoint, so all three methods share a cache of the last evaluation: cost_fn runs once per point Optim visits, and the initial point and the returned result reuse those evaluations. (The result costs one more evaluation only when Optim returns an earlier iterate, after a failed line search or a cost increase.)

AtmosTransport.Adjoints.CSObservationColumnMet Type
julia
CSObservationColumnMet(; p_top, gravity = STANDARD_GRAVITY,
                         temperature = 280.0, humidity = nothing, mass_basis = DryBasis())

The column meteorology with which CSPlacedPointObjective observations choose their model layer at each sampled state (cs_surface_flux_4dvar(...; column_met)). With the air mass mk (kg per cell, k = 1 at the top) of the sampled state and the cell area A:

  • interface pressures p1/2=ptop, pk+1/2=pk−1/2+gmk/A, from p_top (Pa, the model-top interface, the pure-pressure A_ifc[1] of the met model's hybrid coordinate) and gravity (m s⁻²);

  • hypsometric interface heights above the model surface, zk−1/2=zk+1/2+(RdTv,k/g)ln⁡(pk+1/2/pk−1/2), with the layer temperature Tk: a number (K, every layer; the forward sampler's layer_height_temperature_kelvin, 280 K by default), an Output.AbstractLayerTemperature, per-layer panels (an NTuple{6} of arrays laid out like the air mass, with or without the halo, K, for every step), or a vector of such panels with one entry per model step (the state after that step). With the pressure basis TotalFromHumidity (the default) on a dry basis the pressures are the total ones below and Tv,k=Tk(1+0.61qk) the virtual temperature; with DryInterfaces the dry interfaces above and Tv,k=Tk;

  • for TotalFromHumidity on a dry basis (the heights of every placed point observation, pressure placement, averaging-kernel columns), the total interface pressures pk+1/2=pk−1/2+gmk/(A(1−qk)) with the specific humidity qk (kg kg⁻¹ of moist air; nothing, static panels, or one set of panels per step, as temperature).

mass_basis is the basis of the air mass (DryBasis(), the default of transport binaries, or MoistBasis()).

CSObservationRecord(id, date_components, lat, lon, kind,

One observation row of the schema-v2 CSObservationSet.

  • date_components: (year, month, day, hour, minute, second) UTC, Int16, the centre of the sampling window.

AtmosTransport.Adjoints.CSRetrievalColumnObjective Type
julia
CSRetrievalColumnObjective(panel, i, j, area, retrieval, pressure_basis;
                           max_surface_pressure_mismatch_pa = Inf,
                           mismatch_policy = ErrorOnUnplaced())

Averaging-kernel column average of the physical CS interior cell (panel, i, j) (area area, m²): a retrieved column (satellite or TCCON sounding) compared with the model through the retrieval's own layers, pressure weights, averaging kernel and prior (retrieval, an Output.RetrievalColumn). CSStepSchedule(; physics_cadence = nothing, binary_window_contract = false,

               binary_substeps = false, chemistry = NoChemistry(),

The production step a cubed-sphere adjoint differentiates: the step plan and the met windows it runs on. AtmosTransport.Adjoints.IsotropicGaussianCSCovariance Type
julia
IsotropicGaussianCSCovariance(sigma::NTuple{6, AbstractMatrix},
                              correlation_length_cells::Real)

Panel-local CS surface-flux covariance B = D · C · D with isotropic separable Gaussian correlation of length correlation_length_cells (in interior-cell units).

Each panel's (Nc, Nc) grid is treated as periodic and the correlation matrix C is the circulant whose first row is the wrapped Gaussian. L = C^(1/2) (the symmetric square root) is applied via FFT: in spectral space L is multiplication by sqrt(C̃) where C̃ is the real, non-negative spectral eigenvalues of C. The factorization is B^(1/2) = D · L, so (B^(1/2))^T = L^T · D = L · D (since D and L are both symmetric).

The wrapped-Gaussian normalization pins C[i, i] = 1, hence B[i, i] = σ_i² — the diagonal of B recovers the per-cell variance, independent of correlation length.

To keep B^(-1/2) finite at operational Float32 resolutions, each one-dimensional factor of the separable spectrum is floored at its maximum times sqrt(eps(FT)), then renormalized to preserve the unit diagonal. The corresponding minimum two-dimensional covariance eigenvalue is therefore approximately its maximum times eps(FT). This is a precision-aware regularization of unresolved high-frequency modes.

Limitations:

  • Cross-panel correlation is dropped. Each panel is smoothed in isolation; the implicit wrap-around at panel boundaries leaves edge artefacts.

  • The FFT path is CPU-only.

  • The struct carries mutable fft_buf / fft_scratch scratch buffers reused by every apply_B_half! / _adjoint! / _inverse! call. As a consequence the covariance is not thread-safe — concurrent calls on the same instance race on the scratch. Build one instance per worker thread if needed.

AtmosTransport.Adjoints.cs_surface_flux_4dvar Method
julia
cs_surface_flux_4dvar(..., observations, controls; scheme, kwargs...) -> CS4DVarResult

Evaluate the prototype CS surface-flux 4D-Var cost and gradient. Controls are named CSSurfaceFluxControls over CSSurfaceFluxWindows. Observations are scalar CSObservations sampled after the model steps of their CSTimeSampling (one step, or a weighted time window; after convection, the state runtime output sees). CSPlacedPointObjective observations choose their layer, and CSRetrievalColumnObjective observations (averaging-kernel columns) build their weights, at each sampled state from column_met, a CSObservationColumnMet (required when there are any). An averaging-kernel column whose surface-pressure mismatch exceeds its limit is an error, or, under SkipUnplaced, is reported with its simulated value and residual but left out of the cost and the gradient (its stencil is not assimilated). Co-samples (CSObservation(...; assimilate = false): flagged records bound with flagged_records = "cosample", the members of cell averages) are simulated and reported the same way, never in the cost or the gradient, and do not extend the taped run: adding them leaves the cost and the reverse pass's forcing unchanged, bit for bit.

One cost-and-gradient evaluation is two forward runs and one reverse pass (with FullCheckpoint; the other schedules add their recomputation), whatever the number of observations, as in TM5-4DVAR:

  1. a forward run gives the simulated values Hᵢ(x) = Σₛ ωᵢₛ hᵢ(rₛ), each observation's stencil (CSObservationStencil: steps, weights, levels) and its linear functional (weights from the replayed air mass at each sampled step, times ωᵢₛ);

  2. each observation contributes (Hᵢ(x) − yᵢ)/σᵢ² times its functional's weights to the adjoint forcing of each sampled step;

  3. one taped forward run to the last sampled step and one reverse pass, which adds each step's forcing at that step's end, give ∂J_obs/∂E for every step; each control's window collects its steps.

Both runs replay the production step plan of schedule (a CSStepSchedule; default: one step of dt per met window, the full operator suite every step), with the controls' rates in its surface-flux operator. Steps after the last sampled step do not affect the cost and get a zero gradient. checkpoint (FullCheckpoint(), StrideCheckpoint(k), RevolveCheckpoint()) and tape_storage / tape_path select how the one taped run is stored, as in cs_surface_emission_footprint.

scheme is required: inversion callers must name the advection operator whose forward and adjoint they intend to use; there is no hidden numerical default.

Two modes:

  • Unconditioned (default, preconditioner = nothing). Each control's .value is the physical-space control directly. Optional diagonal background terms come from .background + .sigma and are added per control via _background_cost_and_gradient!.

  • Preconditioned (preconditioner non-nothing). Each control's .value is the preconditioned-space variable χ. The function: (1) computes x_k = T(χ_k) per control via the preconditioner; (2) runs the forward simulation with x; (3) reverses through the existing observation-gradient path to get ∂J_obs/∂x_k per control; (4) applies T'(χ_k)^T to get ∂J_obs/∂χ_k and adds χ_k (the derivative of the 0.5 ‖χ‖² regularization). The reported cost is 0.5 ‖χ‖² + observation_cost, the reported gradient is ∂J/∂χ, and the reported controls are the original χ-space inputs. Per-control .background and .sigma are ignored in this mode — the background term comes from 0.5 ‖χ‖², and the background x_b is carried by the preconditioner itself.

preconditioner accepts either a single CSSurfaceFluxPreconditioner (broadcast to every control — the same preconditioner is used for each of them) or a Vector{<:CSSurfaceFluxPreconditioner} aligned 1-to-1 with the control vector. Any other length mismatch throws ArgumentError.

AtmosTransport.Tape.RevolveCheckpoint Type
julia
RevolveCheckpoint()

Logarithmic-memory checkpoint schedule. The driver bisects the step range recursively: at each level it propagates forward from a saved state to the midpoint, reverses the upper half, restores the saved state, then reverses the lower half. Peak snapshot memory is the recursion depth ~ ceil(log2(nsteps)) state-pair copies; total recomputation work is ~O(nsteps × log nsteps) because each step is re-propagated once per recursion level on the path from root to leaf.

This is a tractable bisection variant of Griewank-Walther Revolve — it does NOT compute optimal binomial splits. For nsteps = 2880 (C180 / 14-day campaign) memory caps at ~12 simultaneous snapshots, which is the production target. A future commit can promote this to the optimal Revolve schedule (RevolveCheckpoint(snapshots) with a user-supplied snapshot cap) without changing the public API for single-call inversions.

FullCheckpointO(nsteps)O(nsteps)
StrideCheckpoint(K)O(nsteps/K)~2 × nsteps
RevolveCheckpoint() (bisect)O(log nsteps)O(nsteps × log nsteps)

Parity. Every recorded step starts with production's step-start halo refresh (fill_cs_step_start_halos!), so the halos a step reads are a function of its interior state and a window that restarts at a bisection point records the same states as FullCheckpoint. The default method assumes the source panels are non-Array device-resident buffers (CuArray, MtlArray, …) and records their backend via _register_tape_read_backend!, so the read caches are allocated there on first read. The specialised method for NTuple{6, <:Array} is a no-op so the CPU read path can return mmap views directly without an intermediate copy.

The CUDA extension layers a synchronize = CUDA.synchronize hook on top of the default to amortise asynchronous device transfers; correctness of mmap → device traffic does not depend on that extension because copyto!(::CuArray, ::Array) is synchronous on CUDA.jl.

AtmosTransport.Tape.finalize_tape! Method
julia
finalize_tape!(storage::MmapCSTapeStorage; quiet = false, strict = false)

Sync any pending mmap state, write the TOML manifest, and close the underlying records.bin handle. Safe to call more than once; subsequent calls are no-ops. If the storage owns its temp directory and cleanup_on_finalize is true, the directory is also removed after manifest emission.

By default (strict = false), failures during manifest emission, IO close, or temp-dir cleanup are caught and surfaced via @warn (or suppressed if quiet = true). This matches the temp-dir use case where leaving a partially-finalised storage behind is benign — the directory gets cleaned up by GC or by the caller's mktempdir do block anyway.

With strict = true, manifest- and close-failures are still caught into local error slots (so the IO handle and device cache are released before throwing), but the first such error is rethrown at the end of the function. This is the right setting whenever the storage is rooted at a caller-supplied tape_path and a missing/corrupt manifest.toml would defeat the purpose of persisting the tape.

AtmosTransport.Tape.load_mmap_tape Method
julia
load_mmap_tape(dir; readonly = true) -> MmapCSTapeStorage

Reopen a finalised MmapCSTapeStorage directory written by an earlier session. The loader parses manifest.toml, validates the format version and machine endianness, and rebuilds the in-memory record table so callers can fetch slots via get_record and read them through _tape_panels.

The returned storage has finalised = true and cleanup_on_finalize = false; it never touches the on-disk files except through mmap reads on the existing slots. With readonly = true (the default) _bump_cursor!, _allocate_tape_slot, and stage_panels! throw on mutation; readonly = false opens the binary in r+ mode but is intended for future Phase B work (slot reuse), not for forward appends — appends are blocked by the finalised flag.

Validation:

  • manifest.toml and records.bin must both exist under dir.

  • Format version must equal v1.

  • Endianness must match the loading machine.

  • meta.finalised must be true; a torn tape from an interrupted run is rejected here (Phase B is responsible for repairing it).

  • records.bin must be at least meta.total_bytes long; the cursor is restored from meta.total_bytes.
