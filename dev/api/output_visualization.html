Output and visualization API ​

Output defines snapshot capture and persistence, and observation sampling ([output.observations]: point events and station series sampled at met-window ends). Visualization provides topology-aware field views and optional Makie rendering for those snapshots.

Output ​

AtmosTransport.Output Module
julia
Output

Topology-aware diagnostic output for AtmosTransport runtime products.

This module owns the public NetCDF output contract. Runtime code should capture model state with capture_snapshot and write files with write_snapshot_netcdf instead of defining ad-hoc NetCDF layouts in runner code.

The writer is intentionally topology-dispatched:

  • LatLonMesh writes regular CF lon/lat coordinates.

  • ReducedGaussianMesh writes native cell-indexed diagnostics plus a legacy lon/lat raster view for current debug plots.

  • CubedSphereMesh writes panel-native diagnostics with GEOS-style lons, lats, corner_lons, corner_lats, cell_area, and cubed_sphere metadata so Panoply and downstream tools have enough geometry context to render C-grid snapshots.

New topologies should add methods for the small internal schema/diagnostic functions in this folder; they should not special-case the runner.

Output also owns observation sampling (observations/): the [output.observations] contract, source readers, containing-cell locators, the device column gather, and the append-only _soundings / _sites NetCDF files written by build_observation_sampler's sampler.

AtmosTransport.Output.AbstractPressureBasis Type
julia
AbstractPressureBasis

The interface pressures a pressure-placed record is compared with (pressure_basis): TotalFromHumidity (default) or DryInterfaces. A record's pressure is the total (ambient) pressure, dry air plus water vapour. The air mass of a dry-basis run gives dry interface pressures, pk+1/2=pk−1/2+gmk/A (the weight of the dry air above), which are lower than the total pressure at the same interface by the weight of the water vapour above it: about 0.5 % of the surface pressure for 50 kg m⁻² of precipitable water.

AtmosTransport.Output.RetrievalColumn Type
julia
RetrievalColumn(pressure_pa, pressure_weight, averaging_kernel, prior_profile,
                profile_sigma, surface_pressure_pa)
RetrievalColumn(; pressure_pa, pressure_weight, averaging_kernel, prior_profile,
                  profile_sigma = Float64[], surface_pressure_pa = first(pressure_pa))

The vertical description of one retrieved column average (a satellite or TCCON sounding) on its N retrieval layers, ordered from the surface up:

  • pressure_pa: the N + 1 layer interfaces (Pa, total pressure), surface first, strictly decreasing; the last is the retrieval top (≥ 0);

  • pressure_weight: the pressure weights hi (N, ≥ 0, summing to 1 within RETRIEVAL_WEIGHT_SUM_TOLERANCE);

  • averaging_kernel: the column averaging kernel ai (N, normalized, dimensionless: ∂X/∂xi=hiai);

  • prior_profile: the retrieval prior xa,i (N, dry mole fraction, mol mol⁻¹, in [0, 1]);

  • profile_sigma: optional 1-σ uncertainty σi of the model profile on the retrieval layers (N, mol mol⁻¹, in [0, 1]; empty when absent), the input of the model-error term retrieval_model_error_variance. It is not the retrieval's a-priori uncertainty: the smoothing error is already represented by the averaging kernel;

  • surface_pressure_pa: the retrieval surface pressure (Pa), equal to the first interface (relative tolerance 1e-6).

Every value must be finite. See retrieval_column_weights! for the operator.

AtmosTransport.Output.SnapshotFrame Type
julia
SnapshotFrame

CPU-resident snapshot of one model state at one output time.

air_mass and each entry in tracers keep the topology-native storage shape:

  • LL: (lon, lat, lev)

  • RG: (cell, lev)

  • CS: NTuple{6, Array{T, 3}} with panel interiors (Xdim, Ydim, lev)

Tracer arrays store the model's conservative χ × carrier-air-mass quantity, not mixing ratio or physical kg species. Derived VMR and column diagnostics are computed by write_snapshot_netcdf. tracer_total_mass stores a compensated Float64 sum of that conservative quantity for every tracer. It is kept separately so Float32 visualization payloads cannot degrade global signed mass diagnostics through cancellation or output conversion.

Snapshot storage must be CPU-resident. Use capture_snapshot for model state on any backend; it strips cubed-sphere halos and copies device arrays to the host before constructing the frame.

source
AtmosTransport.Output.TotalFromHumidity Type

pressure_basis = "total" (default): compare a record's pressure with the column's total interface pressures. Specific humidity qk (kg of water vapour per kg of moist air) makes the moist air mass of layer k mk/(1−qk) for a dry air mass mk (kg), so on a dry-basis run the hydrostatic total pressures are

p1/2=ptop,pk+1/2=pk−1/2+gmkA(1−qk),

with A the cell area and ptop the pure-pressure model-top interface A_ifc[1], a total pressure in the met model's hybrid coordinate (level 1 is the top). This inverts the preprocessing's dry conversion Δpdry=(1−q)Δp. On merged or remapped levels the binary carries a dry-mass-weighted q, so the inverse is not exact there; on the golden pre_ll72 binary (ERA5 L137 merged to 34 levels) the rebuilt total surface pressure differs from the stored one by −0.012 Pa on average and 0.125 Pa at most, where the dry interfaces are 169 Pa low on average and 700 Pa at worst. The humidity is the binary's layer-mean specific humidity at the sampled boundary: qv_start / qv_end of lat-lon binaries preprocessed with output.include_qv = true; on cubed-sphere binaries with the GCHP VDIFF payload the window-start VDIFF qv of the next window (the run's last window end takes the ended window's, one window old). Reduced-Gaussian binaries, and cubed-sphere binaries without the VDIFF payload, carry no humidity. On a moist-basis run the air mass already includes the vapour and its interfaces are total pressures without humidity. A dry-basis run whose binaries do not all carry humidity cannot build them: building a sampler that places any record by pressure then fails unless pressure_basis = "dry".

AtmosTransport.Output.begin_observation_day! Method
julia
begin_observation_day!(sampler, date_label, day_index)

Called by the runner before the first window boundary of each input binary. Single-file runs open their files on the first call; daily runs close the previous day's files and open the next pair. Rows are written to the files open at emission time. A binary's last window ends at the next day's 00:00, which is still observed before the next binary opens: with linear interpolation a sounding lands in the file of its own day, and each day's sites file ends with the 00:00 sample of the next day (the first file also holds the initial state at t = 0). With nearest_window, soundings in the first half window after 00:00 are emitted at that boundary and land in the previous day's file.

AtmosTransport.Output.build_observation_sampler Method
julia
build_observation_sampler(spec, state, grid; origin, window_seconds, halo_width,
                          terrain = ObservationTerrain(), has_humidity = false)

Read every source for the days covering window_seconds (seconds after origin, half-open), locate the requests on grid.horizontal, place each in the column (resolve_placement with the static ground fields of terrain, see ObservationTerrain), and prepare the device gather buffers. Requests that cannot be placed fail the build or are skipped and counted, as spec.placement.unplaced says. has_humidity says whether the run's binaries carry specific humidity: on a dry-basis run, pressure-placed requests need it for the total interface pressures of TotalFromHumidity (the default spec.placement.pressure_basis), and the build fails without it unless the basis is DryInterfaces; every window end must then pass humidity to observe_window_boundary!. Output files are opened by begin_observation_day!. NoObservationOutput yields NoObservationSampler().

AtmosTransport.Output.build_observation_set Method
julia
build_observation_set(sources, origin, window_seconds) -> ObservationSet
build_observation_set(sources, origin, dates)

Read every source for the days covering the window, merge sites by id, expand site time lists into point events, keep the point events with window_seconds[1] <= t <= window_seconds[2] (seconds after origin; the dates form uses whole days), and sort them by time (stable). A site id that repeats (across rows, daily files, or sources) must keep its location; time lists of a repeated id are merged, and other schedules must be equal. Per-source counts are logged.

AtmosTransport.Output.capture_snapshot Method
julia
capture_snapshot(model; time_hours=0, halo_width=0, fields=nothing)

Capture air-mass and conservative tracer-storage fields from a TransportModel. Without fields, return a full SnapshotFrame. Passing an OutputFieldSpec returns a SelectedSnapshotFrame containing only requested layers and column diagnostics, plus compensated Float64 totals for the selected tracers.

AtmosTransport.Output.define_cs_horizontal_geometry! Method
julia
define_cs_horizontal_geometry!(ds, mesh::CubedSphereMesh) -> nothing

Define the horizontal geometry of a panel-native cubed-sphere NetCDF file in the open dataset ds: the GEOS-style layout shared by runtime snapshots and cs_native input files. Vertical and time axes are not defined here; each writer owns those.

Dimensions Xdim, Ydim (Nc), Xcorner, Ycorner (Nc + 1) and nf (6). Variables (coordinates and geometry in Float64 whatever the mesh precision):

  • Xdim, Ydim: panel indices 1:Nc, tagged degrees_east/degrees_north ("Fake Longitude/Latitude for GrADS Compatibility", the GEOS-Chem convention) so Panoply and GrADS render a per-panel map; nf (Int32): panel 1:6.

  • lons, lats (Xdim, Ydim, nf): cell-centre longitude and latitude [degrees], from panel_cell_center_lonlat in the mesh's panel convention.

  • corner_lons, corner_lats (Xcorner, Ycorner, nf): cell corners [degrees], from panel_cell_corner_lonlat.

  • cell_area (Xdim, Ydim, nf) [m²]: the mesh's own cell areas (the areas the runtime multiplies fluxes by), with coordinates = "lons lats".

  • cubed_sphere (scalar Int32): grid mapping with grid_mapping_name, cs_definition, cs_coordinate_law, cs_center_law, panel_convention, longitude_of_central_meridian, semi_major_axis = mesh.radius [m] and inverse_flattening = 0. Panel data variables point at it with grid_mapping = "cubed_sphere" and coordinates = "lons lats".

AtmosTransport.Output.resolve_placement Method
julia
resolve_placement(spec::VerticalPlacementSpec, missing_height, request, cell, terrain)
    -> Union{VerticalPlacement, Nothing}

Place a SoundingRequest or SiteRequest in the column of its containing cell by the first of spec.coordinates (AbstractVerticalCoordinate, in preference order) that places it:

  • HeightAboveGroundCoordinate: the record's height above ground h (intake_height, or altitude − elevation with the record's or station's elevation; record_height), else h = altitude minus the DEM ground elevation at the point (altitude_minus_dem). The record is placed h above the model surface.

  • PressureCoordinate: the record's pressure (pressure), when it is valid_pressure (finite and positive).

A record that none of the coordinates place is unplaced (nothing) when it states any vertical coordinate (an intake_height, an altitude, a valid pressure), e.g. an altitude without a ground elevation (no record elevation, no DEM value), or a coordinate the run does not use. One without any vertical coordinate goes to the lowest layer (lowest_layer) under LowestLayerWithoutHeight and is unplaced under UnplacedWithoutHeight (missing_height, from missing_height_rule of the record's source). The model surface height is never used as the true ground.

spec.altitude_placement = AbsoluteAltitudeAbove(h₀) then re-places records placed by a height h≥h0 by their pressure (when pressure is one of the coordinates), else by absolute altitude: the stated altitude, else the ground elevation (the record's, else the DEM value at the point) plus intake_height; a record with neither keeps its height above the ground.

retrieval_column_weights!(H, s, p_half, column::RetrievalColumn) -> H
retrieval_column_weights!(H, s, p_half, r, h, a) -> H

Weights of the averaging-kernel column on the model layers: with the model profile xk (dry mole fraction, k = 1 at the top),

X=∑kHkxk+c,Hk=∑ihiaiRik,c=∑ihi(1−ai)xa,i

AtmosTransport.Output.retrieval_model_error_variance Method
julia
retrieval_model_error_variance(column::RetrievalColumn) -> Float64

The model-error variance of the averaging-kernel column from the uncertainty σi of the model profile on the retrieval layers (profile_sigma), the layers taken independent: σmod2=∑i(hiaiσi)2, the operator's weights on the retrieval layers, squared, times the profile variance. Zero when the column gives no profile_sigma. It depends on the record only, so it is fixed for an inversion and the cost stays quadratic.

This is analogous to, not the same as, TM5-4DVar's model error: its CH4 TROPOMI routine (averaging_kernels.F90, line 669, and Satellite.py of the CH4 project) evaluates ∑kHk2σk2 with the weights H=(ha)R on the model layers and the spread of the modelled profiles σk from its track file, and its OCO-2 routine adds a column model error instead. profile_sigma is not the retrieval's a-priori uncertainty, whose effect (the smoothing error) the averaging kernel already represents.

AtmosTransport.Output.retrieval_rebin_matrix Method
julia
retrieval_rebin_matrix(p_half, column::RetrievalColumn) -> Matrix{Float64}
retrieval_rebin_matrix(p_half, r) -> Matrix{Float64}

The redistribution matrix R (N × Nz, retrieval layers surface first, model layers top first) of TM5-4DVar's inv_rebin (averaging_kernels.F90, lines 60-146) on the model column stretched onto the retrieval column: Rik is the pressure overlap of stretched model layer k with retrieval layer i divided by the thickness of layer i, so (Rx)i is the pressure-weighted mean of x over retrieval layer i. The outermost retrieval interfaces are those of the stretched model column (TM5's choice; they equal the retrieval surface and top to rounding). Every row sums to 1 and every column k distributes all of the stretched layer: ∑iRikΔpir=Δsk (the rebin conserves the column integral of x).

AtmosTransport.Output.stretch_model_interfaces! Method
julia
stretch_model_interfaces!(s, p_half, surface_pa, top_pa) -> s

TM5-4DVar's stretch of the model column onto a retrieval column (averaging_kernels.F90, lines 213-219): the model interface pressures p_half (Pa, top first, p_half[end] the model surface pressure ps, p_half[1] the model top pt) mapped linearly so that the model surface falls on the retrieval surface psr (surface_pa) and the model top on the retrieval top ptr (top_pa),

sk=μpk+c,μ=psr−ptrps−pt,c=12[(psr−μps)+(ptr−μpt)].

Each model layer keeps its share Δpk/(ps−pt) of the column, so the pressure-weighted mean of any profile over the stretched layers is its mean over the model layers: the stretch moves the model column onto the retrieval's pressure range without adding or removing air.

Visualization ​

Field selection uses typed values. Pass ColumnMean(), ColumnSum(), LevelSlice(), or SurfaceSlice() as the transform keyword to fieldview; LevelSlice() also requires level. Pass NativeUnit() or PPMUnit() as unit, and pass AllFrames() to frame_indices to select every frame. These selectors are exported by AtmosTransport.Visualization, not by the top-level module. For example:

julia
using AtmosTransport.Visualization
snapshot = open_snapshot("output.nc")
surface = fieldview(snapshot, :co2; transform=SurfaceSlice(), time=1,
                    unit=PPMUnit())
levels = fieldview(snapshot, :co2; transform=LevelSlice(), level=10, time=1)
