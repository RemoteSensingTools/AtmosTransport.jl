Code map ​

Generated by scripts/checks/check_structure.jl; edit the source or mirror data, then run:

bash
CUDA_VISIBLE_DEVICES= julia --startup-file=no --project=test scripts/checks/check_structure.jl --write-code-map

Read this map and the folder README before editing. Each folder owns its immediate Julia files; subfolders have separate budgets of 65,000 tokens (bytes / 3.5). Existing oversized folders must shrink.

Dependencies include static imports, qualified references, shared-module name uses, and includes. They describe today's code; src/LAYERS.toml declares their allowed order and existing exceptions. Public counts are distinct resolved (module, name) pairs declared public or export, assigned to their definition folders (or the module entry folder if no definition is located); facade re-exports are counted at the owner. Mirrors come from test/structure/mirrors.toml, seeded from the cleanup inventory's units and helper index; an empty list means no recorded pair.
