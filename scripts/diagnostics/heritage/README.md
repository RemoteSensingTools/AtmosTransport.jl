# Heritage diagnostics

Scripts in `heritage/` are not part of a maintained workflow. They are kept
for reference, as the method or evidence of a finished study, until they are
trimmed. They may hard-code the paths, dates and data of that study, and they
are not tested; check imports and inputs before running one. Retired scripts
are listed under "Retired scripts" in [`scripts/README.md`](../../README.md).

"Fingering" below is the GEOS native mass-flux SH-UTLS noise documented in the
developer note `GEOS_MASS_FLUX_UTLS_FINGERING.md`; M is its column
MFXC/DELP continuity residual.

| Script | Purpose | Why it is here |
|---|---|---|
| `check_cs_binary_seam_mirrors.jl` | Checks whether on-disk CS horizontal mass fluxes are invariant under the preprocessing seam-mirror operation (`sync_all_cs_boundary_mirrors!`) | Generic real-binary check that no test covers; from the June 2026 air-mass-reset work |
| `compare_at_vs_geoschem_c180.jl` | Compares an AtmosTransport C180 Dec-2021 snapshot with GEOS-Chem CATRINE 3-hourly files (optional GLMakie plots) | Superseded by `../catrine_compare_vs_geoschem.py`; the CATRINE Dec-2021 developer note documents its CLI. GLMakie is not in the project |
| `compare_c180_binary_mass_fluxes.jl` | Compares horizontal mass-flux speeds (plus roughness, temporal jumps, edge vs interior, cm rates) of ERA5 and GEOS-IT C180 binaries on a common lat-lon grid | Generic two-binary audit configured by env vars; compiles against the current API and a kept diagnostic cites it. Its default inputs are gone; pass v4 binaries via env |
| `compare_c180_window_tendencies.jl` | Compares ERA5 and GEOS-IT C180 tracer tendencies (dCO2/dt at 1/2/4-step lags; column, surface, 850/500/250 hPa) on a common lat-lon grid | Only lagged-tendency comparison of two met paths; uses the current Grids/Regridding API |
| `compare_convection_schemes.jl` | Compares convection schemes on the 4-tracer single-layer IC experiment (per-layer means, peak layer, mass above the initial layer, total mass) | Analysis companion of `config/runs/convection_compare_4tracer/` from the May 2026 convection audit; usage lines point at `/temp1` outputs |
| `compare_era5_geosit_met.jl` | Audits an ERA5 C90 binary vs native GEOS-IT C180 met (mass fluxes, DELP, QV, PS) on a common dry/moist basis for 2021-12-01 | Cannot run: its binary is gone and it reads header keys v4 CS binaries lack. Two `src/` comments cite it as evidence that MFXC is dry |
| `compare_era5_n320_pipeline_vs_catrine.jl` | Runs the ERA5 N320 to C180 preprocessing for one hour and compares PS and T850 with the CATRINE GEOS-Chem snapshot | Independent-reference recipe for the N320 path; its calls match current signatures. A developer note cites it |
| `cx_implied_dp_vs_delp.jl` | Compares the Courant-implied flux thickness MFXC/CX/area with archived DELP, level by level, to localize M | Evidence for the developer note's finding that M is temporal, not geometric; its config and raw GEOS-IT 2021-12-11 data exist |
| `decompose_transport_vs_flux_iav.py` | Splits transported XCO2 IAV into flux-driven and transport-driven parts using the JULES-ES NEE climatological control run (C30) | Analysis of a finished study; reusable linear-decomposition recipe |
| `finger_era5_vs_geos.py` | Fingering metric: grid-scale Laplacian RMS of `co2_natural` (lat < -30) for GEOS vs ERA5 runs | The developer note's definition of the metric; runs on existing inputs. `omega_tracer_finger_and_mass.py` is the general form |
| `fingerfix_proto_cm-hyperdiffusion-via-potential.jl` | Fingering fix: bi-Laplacian hyperdiffusion of each layer's div_h via a Poisson flux potential (continuity exact); sweeps nu and scores r_vdiv | Runner-up fix (r_vdiv 0.211, commit 3c7c8b33) and the only cube-native fix that needs no A3dyn OMEGA: the fallback for a GEOS product without OMEGA |
| `fingerfix_proto_omega-consistent-flux-reconstruction.jl` | Prototype OMEGA-consistent 3-D flux reconstruction (least-norm flux potential plus hyperdiffusive blend) | Production version is `src/Preprocessing/transport_binary/geos_cs_omega.jl`; a `src/` comment cites this prototype as the validation record. Hard-codes GEOS-IT Dec-2021 paths |
| `linrood_la_footprint_c180.jl` | Plan 25: 6-hour LinRood adjoint surface-emission footprint at LA on C180 from a real ERA5 binary; writes bin and CSV to `artifacts/` | Only real-met C180 adjoint footprint driver (`../linrood_la_footprint.jl` uses synthetic C24 winds); feeds `plot_linrood_la_footprint_c180.py` |
| `meridional_curtains_fullphys_dec1-3.py` | Full-physics latitude-pressure curtains of `co2_natural` at three tropical longitudes: GEOS-Chem vs GEOS-native vs OMEGA-consistent vs ERA5 (Dec 1-3 2021) | Latitude-pressure curtains; the maintained curtain scripts draw longitude-pressure curtains. `GCDIR` must be repointed to `catrine-geoschem-runs/C180` |
| `moist_budget_IT_vs_FP.jl` | QV-free column residual M, GEOS-IT C180 vs GEOS-FP C720 | Root-cause evidence (FP/IT ratio 1.03) cited by the developer note; compact reference computation of M for screening new GEOS products |
| `ocean_xco2_monthly_range.jl` | Monthly column-mean XCO2 per tracer from the last frame of each daily ATMSNAP1 file (ECCO-Darwin ocean tracer) | One-off report of the July 2026 ECCO-Darwin check; `../extract_cs_column_means.jl` is the maintained extractor |
| `omega_tracer_finger_and_mass.py` | Fingering roughness plus global CO2 burden closure for OMEGA vs native-GEOS vs MERRA-2 adv-only C180 runs | Validation recipe of the production `omega_consistent` closure (commit 08a74768); reusable for a new cm closure. Hard-codes the main checkout's `geos_L72_coefficients.toml` |
| `per_column_depth_histogram.jl` | Histogram of per-column TM5 convection active depth (from detu) over a C180 binary | Config comments cite it for measured convection reach; walks the payload through private `_cs_section_elements` |
| `plot_c30_trendy_hovmoller.py` | Hovmoller and zonal growth-rate figures for the 3-model (CLM, JULES-ES, ORCHIDEE) C30 TRENDY run vs OCO-2 and GRESO | Run replaced by the 23-model campaign; `../rank_trendy_hovmoller.py` covers it except the GRESO growth-rate panel. Hard-codes a GRESO CSV in another user's home |
| `plot_convection_profiles_per_panel_percentiles.jl` | Per-panel 10/50/90 percentile profiles at t=24 h for three convection schemes, 4-tracer spike experiment (log axis) | Template of the retired percentile-plot family, whose members differ only in scheme list, labels or axis scale |
| `plot_cs_column_adjoint_2day_map.jl` | Two-day CS column-mean adjoint footprint map from real binaries, with physics, scheme, tape-storage and CUDA options | Broken since 2026-05-20 (calls about 17 now-unexported names unqualified). Only real-met adjoint footprint recipe, relevant to inversions; largest trim candidate (1370 lines) |
| `plot_linrood_la_footprint.jl` | CairoMakie map of the LA LinRood footprint `.bin` from `../linrood_la_footprint.jl` | Plotting companion of the kept demo; needs CairoMakie (docs environment only) |
| `plot_linrood_la_footprint_c180.py` | Matplotlib plot of the C180 LA footprint CSV | Plots the CSV written by `linrood_la_footprint_c180.jl` |
| `plot_sif_fluxcom_hovmoller.py` | Monthly zonal GPP totals of the 2021 SIF and FLUXCOM-X drivers | Recipe for flux-driver Hovmollers; hard-codes a `/kiwi-data` FLUXCOM-X pilot path |
| `plot_trendy_allmodels_nee_decomposition.py` | Decomposes monthly global NEE anomalies of 23 TRENDY v14 S3 models into NPP, Rh and fire and scores each against the OCO-2 GRESO growth-rate anomaly | Figures of the SIF-GPP/TRENDY study, cited by two memos; its two input JSONs came from a session scratchpad (`--scratch`) |
| `plot_trendy_s3_hovmoller_ensemble.py` | TRENDY v14 S3 2021 C90 monthly GPP/TER Hovmoller ensemble atlases of the flux drivers | Figures of the 2021 driver ATBDs (v0.1, 2026-07-22), which cite it |
| `r2_slope_3d_vs_geoschem.py` | Full-3D per-cell R2 and regression slope of a 4-tracer run vs GEOS-Chem per timestep | Dec-2021 campaign gate; `../catrine_compare_vs_geoschem.py` has column and band R2, not the per-cell metric. Two configs name it; hard-codes the GC directory and start time |
| `synthetic_closed_advection_conservation.jl` | Closed-domain air and tracer mass conservation of LL and CS (cross-panel) advection across schemes and float types on synthetic fluxes | Standalone side-by-side report (LL, CS interior and mirrored seams, a deliberately invalid seam) over one and eight steps; the conservation itself is tested in `test/core/test_cubed_sphere_advection.jl` |
| `verify_emissions_vs_geoschem.jl` | Compares the applied surface emissions (loader, conservative LL to CS regrid, temporal scheme) with GEOS-Chem `Emis*` per species, timestep and cell on C180 | No maintained tool compares applied fluxes per cell. Repoint `BIN` and set `GC_DIR` before reuse |
