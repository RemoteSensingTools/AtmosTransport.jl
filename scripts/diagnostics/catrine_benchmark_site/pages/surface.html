Near surface and boundary layer

The lowest 10 % of each column's air mass (surface to ≈ 910 hPa), where the emitted tracers enter the atmosphere. Rn-222 and fossil CO₂ start from zero everywhere, so their near-surface fields test boundary-layer mixing, convection and emission injection without any initial-state effect.

What to know about the near-surface comparison

  • Boundary-layer mixing as in GCHP. The MERRA-2 run uses GEOS-Chem's non-local boundary-layer mixing (VDIFF) and GEOS convective mass fluxes, like GCHP, on the same MERRA-2 boundary-layer height (identical to GCHP's Met_PBLH to 0.006 m RMS). The ERA5 run uses TM5's diffusion and TM5 convection on ERA5 fields, so it is expected to differ more from GCHP near the surface.
  • The MERRA-2 run is the OF-108 rerun. A roundoff check in the non-local mixing sent whole-column emissions to the lowest layer when any layer was slightly negative; the fix (merged before this run) applies the fallback only where the redistribution itself makes a layer negative or a negative layer more negative. The ERA5 run does not use this code path.
  • Two exact v0.5 changes raise near-surface Rn-222 relative to earlier AtmosTransport runs: the symmetric half-window radioactive-decay split (+0.38 %) and the dry-air mass now matching GCHP's (+0.42 % in mole fraction). Both are corrections; GCHP itself decays Rn-222 with a 3.83 d half-life instead of the protocol's 3.8235 d.
  • Open finding OF-104: relative to GCHP, AtmosTransport keeps slightly more of its Rn-222 in the lowest 10 % of the air mass (measured ≈ 0.5–1 % in the pre-fix MERRA-2 runs); emissions, boundary-layer height, dry pressure and decay are ruled out, so the cause is in the mixing operators. It is being followed up.
