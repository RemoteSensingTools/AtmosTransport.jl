Operator cost breakdown

Where the time of an all-operator run goes, at 12 tracers, from runs with one operator set each. The input floor is the run with no operator (met input and time stepping); each operator's cost is its run minus that floor; emissions = (adv+emis) − adv; the remainder is what the all-operator run costs beyond the sum, and it can be negative.

Segments left of zero are negative components. Black tick = the measured all-operator time. Tap or hover a bar for the values.

Values

Seconds per simulated day (means of the passes); percentages of the all-operator time.
